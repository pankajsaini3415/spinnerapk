## 📱 How to Use

### For Developers

1. **Clone the repository:**
   ```bash
   git clone https://github.com/pankajsaini3415/spinnerapk.git
   cd spinnerapk
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Run on Android:**
   ```bash
   npm run android
   ```

4. **Run on iOS:**
   ```bash
   cd ios && pod install && cd ..
   npm run ios
   ```

### For Users

1. **Launch the app**
2. **Enjoy the animated splash screen** (3.5 seconds)
3. **Browse the web content** in the integrated WebView
4. **Navigate to a Wingo page** to see the premium results card
5. **View real-time updates** automatically
